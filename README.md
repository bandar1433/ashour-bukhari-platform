# حلقات عاشور بخاري — v2.2 (مهيأة لـ AppDeploy)

تطوير للنسخة المرفقة v2.1، مع الاحتفاظ بالهوية البصرية وجداول Neon الموجودة.

## حالة التسليم
- فحص TypeScript ناجح، و10 اختبارات وحدة لحدود الصلاحيات والتحقق من المدخلات ناجحة.
- نجح تجميع الواجهة عبر Vite مع إبقاء مكتبة AppDeploy خارج حزمة الفحص المحلية لأنها تُحقن على المنصة؛ ليس هذا اختبار تشغيل حي للمكتبة.
- لم ينفذ اختبار تكاملي على Neon من التطبيق، ولم تُنفذ اختبارات المتصفح التشغيلية بعد.
- ملف tests/tests.json يصف اختبارات التشغيل اللاحقة للنشر؛ يحتاج اتصال قاعدة بيانات وحسابات اختبار مصرحاً لها. لا تتجاوز المصادقة لتشغيل الاختبارات.
- الاتصال الآمن DATABASE_URL لم يُدخل في AppDeploy بعد. لا تضعه في الكود أو ملفات النشر.
- الرابط القديم https://app-vrtnaa.v2.appdeploy.ai/ مرجع للنسخة السابقة. الحساب المتصل حالياً لا يملك صلاحية تعديله. لا تنشر إلى معرّفه قبل استعادة الصلاحية.

## المنجز
1. استخدام تسجيل دخول AppDeploy والتحقق من الهوية في جميع واجهات البيانات الخاصة.
2. صلاحيات حسب حساب قاعدة البيانات: المدير، مدير المركز، المشرف، المعلم، الطالب، ولي الأمر؛ وإزالة اختيار الدور التجريبي.
3. إضافة المراكز والحلقات وحسابات المعلمين والطلاب، وربط الطالب بحساب الطالب أو ولي الأمر.
4. إضافة الطلاب ونقلهم بين حلقات المركز وتغيير حالتهم.
5. تسجيل الحضور وعرض حالته المحفوظة بحسب التاريخ.
6. الحفظ والمراجعة والتسميع مع التحقق من أرقام السور والآيات وفق العد الكوفي والدرجات.
7. النقاط وسجل الحركة في عملية ذرية؛ الجوائز وتسليمها بخصم الرصيد والمخزون داخل معاملة.
8. تقرير طالب بفترة زمنية، وحضور وحفظ وتسميع وسجل نقاط؛ الطباعة والحفظ PDF من المتصفح.
9. نشر الأخبار والفعاليات والإنجازات.
10. تحسين النماذج للجوال ومعالجة رسائل الأخطاء والحالات الفارغة.
